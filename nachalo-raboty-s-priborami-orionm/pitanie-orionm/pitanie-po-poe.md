ORIONm поддерживает технологию PoE, предусматривающую передачу данных и питание по одному кабелю. В следующих разделах объясняется, как подключить и настроить питание ORIONm по PoE.

<color color="red">*Дополнительные сведения об использовании интерфейса PoE для передачи данных см. в разделе 3.3.2. Подключение через PoE.*</color>

**Выбор PoE-инжектора**

В таблице ниже представлены краткие характеристики PoE-интерфейса ORIONm, которые могут служить справочной информацией при выборе подходящего PoE-инжектора для решения конкретных задач:

| **Категория на основе стандартов PoE** | 802\.3at Type 2, LTPoE++ |
|----------------------------------------|--------------------------|
| **Разъем**                             | RJ45                     |
| **Диапазон входного напряжения**       | 42–57 В пост. тока       |
| **Требуемый источник питания**         | До 40 Вт                 |

При выборе PoE-инжектора для ORIONm также следует учитывать потенциальные требования к питанию той или иной конфигурации системы (типы работающих модулей и/или датчиков, включение Wi-Fi, использование локального хранилища и т.д.), поскольку это напрямую влияет на выбор подходящего устройства.

**Примечание:**

Если вы намерены использовать PoE в промышленной среде, обратитесь к руководителю лаборатории за советом о том, какой сторонний PoE-инжектор подойдет лучше всего. Кроме того, можно приобрести внешние решения -- аккумуляторные PoE-инжекторы. Свяжитесь с поставщиком для получения дополнительной информации.



#### Подключение питания по PoE

![](./pitanie-po-poe.png){width=1580px height=389px}



При питании ORIONm по интерфейсу PoE подключите питание следующим образом:

**1\.**      Вставьте PoE-инжектор в подходящую сетевую розетку (следуйте инструкциям по эксплуатации и безопасности, предоставленным изготовителем PoE-инжектора).

**2\.**      Подключите PoE-порт PoE-инжектора к разъему PoE на ORIONm, используя экранированный, прямой кабель Gigabit Ethernet (соблюдайте местные правила техники безопасности при прокладке кабелей PoE).

**3\.**      PoE-индикатор ORIONm загорится голубым при обнаружении PoE-питания (но не использовании его в качестве основного источника питания). Когда прибор перейдет на питание по PoE, индикатор загорится зеленым.

**Внимание:**

Учтите, что экран экранированного кабеля Ethernet может стать источником паразитного контура заземления.

**Примечание:**

Цвет индикатора может меняться по причинам, не связанным с подачей питания по PoE. Например, спустя несколько секунд индикатор может загореться зеленым, указывая на состояние питания (заряда) аккумулятора ORIONm. <color color="red">*(Дополнительные сведения см. в разделе 3.5.2.5. Индикаторы состояния батареи (пункт 5 и 6)).*</color>
