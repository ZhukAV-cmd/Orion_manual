На передней панели ORION-Rx предусмотрен разъем Gigabit Ethernet (1000 BASE-T) для подключения совместимых кабелей Ethernet. При подключении к ORION-Rx по Ethernet допустимо использовать только кабель UTP категории 5E. Это обеспечит правильное экранирование сигналов по всей длине кабеля.

Конфигурация интерфейса Ethernet ORION-Rx по умолчанию следующая:

·      Автоматическое согласование по стандарту IEEE 802.3 для определения скорости и дуплексного режима канала;

·      Автоматическое согласование по стандарту IEEE 802.3 для определения скорости и дуплексного режима канала;

·      Протокол mDNS включен с именем по умолчанию: DecaQ\_\[серийный номер на нижней стороне прибора\], например DecaQ_1234S5678

·      Режим клиента DHCP включен (настройка по умолчанию: автоматическое назначение частного IP-адреса, например 169.254.119.144, если не удается обнаружить DHCP-сервер).

Для проверки подключения к DECA**Q** используйте браузер с поддержкой mDNS. Введите URL-адрес [http://MKII_1234S5678.local](http://MKII_1234S5678.local/) (замените «1234S5678» серийным номером ORION-Rx).

В браузере должна открыться страница обзора системы ORION-Rx. Параметры конфигурации интерфейса Ethernet при запуске ORION-Rx можно изменить на страницах настройки сетевых параметров веб-сервера.

Для использования интерфейса Ethernet просто подключите кабель Ethernet. Прибор ORION-Rx выполнит автоматическое обнаружение кабеля Ethernet и его инициализацию как основного сетевого интерфейса. Прибор оснащен двумя разъемами RJ45. Для подключения ORION-Rx используйте тот, который расположен ближе к метке ENET или PTP. *Разъем, расположенный дальше от метки ENET или PTP, зарезервирован для дальнейшего использования.*

После загрузки на дисплее интерфейса отобразится IP-адрес системы. После этого можно изменить настройки сети через веб-сервер (с IP-адресом в качестве гиперссылки).



### **Диапазон подключения и кабели Ethernet**

Для подключений типа «Gigabit Ethernet по медному кабелю» (1000BASE-T) используются кабели длиной до 100 м. Если требуется большая длина, потребуется установить активные ретрансляторы через каждые 100 м. Учтите, что при увеличении длины кабелей Ethernet повышается сопротивление, что приводит к снижению качества передачи питания и нагреву кабеля. Следовательно, рекомендуется использовать кабели Ethernet категории 6A из-за их меньшего сопротивления, особенно если для измерений требуется длинный кабель.
